Generative UI for Data Visualization

Describe a question in plain language. A small intent-parsing engine reads it, picks the chart form that best answers it — trend, comparison, share, distribution, or correlation — and renders it live, the way a generative interface would assemble UI on demand instead of shipping one fixed dashboard.

Type a question above, or pick a starter prompt — the UI is generated, not pre-built.

How the generation works

01 · PARSEKeywords in the prompt are matched to an intent — trend, comparison, share, distribution, or correlation.
02 · SELECTEach intent maps to the chart form that answers it fastest: line for trend, bars for comparison, donut for share, histogram for distribution, scatter for correlation.
03 · BINDA matching sample dataset is attached and scaled to the chart's axes and legend automatically.
04 · RENDERThe chart, legend, tooltips, and a data table are assembled into one card — a fresh UI per question, not a fixed dashboard.
A concept exploring how AI-driven interfaces could compose visualization UI on the fly from intent, rather than requiring a pre-built chart for every question. Part of Experimental Projects. Built by Srinivasan.
